# Мулти-таймер за обратно броене

Този проект представлява модерно уеб приложение за управление на таймери за обратно броене.

## Покрити изисквания и функционалности:
* **Персонализирани таймери:** Възможност за създаване на нов таймер с избрано от потребителя име и начален интервал в точен формат (**чч:мм:сс**).
* **Независима мултифункционалност:** Приложението поддържа неограничен брой едновременно работещи таймери (**минимум 3 по подразбиране** при зареждане), като всеки работи напълно независимо от останалите.
* **Индивидуален контрол:** Всеки таймер разполага със собствени бутони за **Старт**, **Пауза** и **Рестартиране (Нулиране)**.
* **Визуален прогрес бар:** Динамична графична лента за всеки таймер, която плавно се смалява и показва оставащото време в реално време.
* **Двойна нотификация при достигане на 0:**
  * **Визуална аларма:** Картата на изтеклия таймер започва да мига в червено и се появява текстово съобщение (`alert`).
  * **Звукова аларма:** Използва се вграденото `AudioContext` API на браузъра за генериране на звуков сигнал (Бийп), което елиминира нуждата от зареждане на външни MP3 файлове.
